```bash
docker container run -it \
  -p 80:3001 \
  -v /:/mnt/host:ro \
  --privileged \
  ghcr.io/malikons/dashdotplus
```

## Configuration

Config options can optionally passed using the
[`--env`](https://docs.docker.com/engine/reference/commandline/run/#set-environment-variables--e---env---env-file)
flag.

```bash
docker container run -it \
  --env DASHDOT_ENABLE_CPU_TEMPS="true" \
  # ...
```

## GPU Support

GPU support needs the CUDA-based image, which this repository's CI does
**not** publish. Build it yourself - it is identical to the standard image
apart from its base - then run it with `--gpus all`:

```bash
docker build -f docker/Dockerfile.nvidia --build-arg VERSION=1.0.0 -t dashdotplus:nvidia .
```

```bash
docker container run -it \
  -p 80:3001 \
  -v /:/mnt/host:ro \
  --privileged \
  --gpus all \
  --env DASHDOT_WIDGET_LIST="os,cpu,storage,ram,network,gpu" \
  dashdotplus:nvidia
```
