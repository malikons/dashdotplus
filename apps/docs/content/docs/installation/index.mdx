<Callout title="No Helm chart yet" type="info">
The community Helm chart documented upstream deploys the original dashdot
image, not this fork, so it is not offered here. On Kubernetes, point a
plain Deployment at `ghcr.io/malikons/dashdotplus` instead - the
[Docker guide](./docker) covers the required mounts and environment
variables, which carry over unchanged.
</Callout>
